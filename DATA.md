# Data

Everything needed to reproduce the paper is in this repository.

| Path | Content | Produced by |
|---|---|---|
| `data/raw/overture/index_<release>.parquet` | bounding box of every row group of the Overture buildings release | `scripts/01a_fetch_buildings.py` |
| `data/raw/sionna_scenes/<city>/building.geojson` | building footprints with height and floor attributes (Overture Maps release in `configs/data/sionna_cities.yaml`) | `01a_fetch_buildings.py` |
| `data/raw/sionna_scenes/<city>/building_source.json` | release, query box, footprint sources, attribute coverage | `01a_fetch_buildings.py` |
| `data/raw/sionna_scenes/<city>/scene_meta.json`, `scene.xml` | scene definition and height provenance (`*.ply` meshes are regenerated by `01_build_scenes.py`) | `01_build_scenes.py` |
| `data/raw/sionna/<city>/measurements.parquet` | one row per ray-traced cell and site: `bs_id`, `rx_lat`, `rx_lon`, `rx_h`, `tx_lat`, `tx_lon`, `tx_h`, `dist_m` (3-D, m), `pathloss_db` | `01b_raytrace.py` |
| `data/raw/sionna/<city>/origin.json` | solver version, backend, rays per site, cell size, depth, mechanisms, cut-off, siting policy, run time | `01b_raytrace.py` |
| `data/raw/sionna_7p5/<city>/…` | the same sites ray traced at 7.5 GHz (`configs/data/sionna_cities_7p5.yaml`) | `01b_raytrace.py` |
| `data/raw/sionna_randsite/<city>/…` | four cities with sites on randomly chosen rooftops, 3.5 GHz (`configs/data/sionna_cities_randsite.yaml`) | `01b_raytrace.py` |
| `data/raw/sionna_ext/<scene>/…` | the Munich, Etoile and Florence scenes of Sionna RT: footprints derived from the meshes, 8 rooftop sites, 3.5 GHz links | `17_external_scenes.py --raytrace` |
| `data/processed/sionna/<city>/tiles.parquet` | tile grid, labels (γ, P_L0), shrinkage weight, iid and CR2 cluster-robust standard errors, 32 descriptors | `02_build_tiles.py` |
| `data/processed/sionna_7p5/<city>/tiles.parquet` | the same for the second band | `02_build_tiles.py` |
| `data/splits/loco.json` | leave-one-city-out splits | `03_make_splits.py` |
| `outputs/tables/*.csv`, `outputs/sionna_7p5/tables/*.csv` | every result reported in the paper | `01c`, `01d`, `02`–`16` |

Coordinates are WGS84. Path loss is in dB for isotropic antennas (3.5 GHz, or
7.5 GHz for `sionna_7p5`). Cells beyond the 150 dB coupling-loss cut-off are
not stored. The raw files are the solver output; the analysis drops, on
loading, links more than `qc_fspl_margin_db` (6 dB) below free space
(`terranet.data.labels.load_links`), rare overweighted cells of the Monte
Carlo radio-map estimator (`scripts/01d_rt_outliers.py`).
